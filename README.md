# CITY LIFE 3D — NOVA BAY MEGA WORLD (V3)

نسخة تطوير كبيرة للعبة عالم مفتوح ثلاثية الأبعاد للأندرويد، مكتوبة بلغة C باستخدام raylib 5.5 وقالب raymob. يعتمد المشروع حالياً على إنشاء البيئة والمجسمات برمجياً، وتوليد موسيقى أصلية داخل اللعبة.

> ملاحظة مهمة: هذه نسخة عالم مفتوح إجرائية محسّنة وليست لعبة AAA أو رسومات واقعية فوتوغرافية. لا تتضمن الحزمة حتى الآن ملفات سيارات أو شخصيات أو مبانٍ عالية التفاصيل بصيغ FBX/GLTF، ولا أغاني مسجلة بصيغة MP3. السيارات والمباني الحالية مجسمات raylib إجرائية، والموسيقى توليد صوتي أصلي داخل الكود. الوصول إلى الواقعية الفوتوغرافية يتطلب إضافة أصول ثلاثية الأبعاد وخامات وصوتيات احترافية ثم ضبط الأداء على أجهزة Android مختلفة.

## ما تمت إضافته في V3

- توسيع المدينة من شبكة 8×8 إلى شبكة 16×16 من الكتل العمرانية، مع مساحة لعب تقارب 768×768 وحدة عالمية.
- حتى نحو 900 مبنى إجرائي موزعة على أحياء ومناطق مختلفة، مع ارتفاعات أكبر في مركز المدينة ومبانٍ منخفضة في المنطقة الصناعية.
- شبكة شوارع أوسع، أرصفة وخطوط طرق، ساحل ومياه وشاطئ وممشى بحري.
- منطقة مطار إجرائية فيها مدرج وعلامات ومبنى ركاب وبرج مراقبة وطائرة مبسطة.
- ميناء حاويات إجرائي مع حاويات وأرصفة ورافعات مبسطة.
- 32 مركبة مرور متحركة و44 شخصية مشاة.
- 8 أشكال سيارات إجرائية: سيدان، رياضية، SUV، بيك أب، شرطة، فان، كلاسيكية وتاكسي. يمكن تغيير شكل سيارة اللاعب من زر المرآب.
- قيادة محسّنة، نيترو، فرامل يد، انجراف، دخان إطارات وآثار انزلاق ونقاط انجراف.
- 6 مهمات توصيل موزعة عبر مناطق مختلفة من العالم.
- دورة نهار وليل، سماء متغيرة، إضاءة نوافذ ليلية، أمطار مرئية ومؤشر منطقة وطقس.
- ثلاثة مسارات موسيقية إلكترونية أصلية مولدة داخل اللعبة، مع تبديل المحطة، بالإضافة إلى صوت محرك اصطناعي متغير النبرة.
- تحكم باللمس، كاميرا تتبع تتباعد مع السرعة، خريطة مصغرة وواجهة معلومات مطورة.

## التحكم على الهاتف

- العصا اليسرى: المشي أو توجيه السيارة.
- ACTION: ركوب السيارة أو الخروج منها أو التفاعل مع المهمة.
- GAS / BRAKE: التسارع والفرامل.
- HANDBRAKE: فرامل اليد والانجراف أثناء القيادة.
- NITRO: زيادة التسارع أثناء الضغط على الزر أسفل يسار الشاشة عند الجلوس في السيارة.
- زر NOVA FM: الانتقال بين المسارات الموسيقية الثلاثة.
- زر المرآب: تدوير أشكال السيارات الثمانية.
- زر II: إيقاف اللعبة مؤقتاً.

## التحكم على الكمبيوتر عند الاختبار

- WASD أو الأسهم: حركة اللاعب وتوجيه السيارة.
- E: التفاعل / ركوب السيارة.
- Shift: بنزين.
- Space: فرامل أو قفز.
- Left Alt: فرامل اليد والانجراف.
- N: نيترو.
- M: تشغيل/إيقاف الراديو.
- C: تغيير شكل السيارة.
- Esc: إيقاف مؤقت.

## بناء APK عبر GitHub Actions

الملف `.github/workflows/android-apk.yml` يستخدم GitHub Actions على Ubuntu، يجهز Java 17 وAndroid SDK وNDK وCMake، يجلب قالب `KarvinJ/raylib-mobile`، ينسخ `src/main.c` إلى القالب، ثم ينفذ `:app:assembleDebug`.

بعد رفع المشروع إلى مستودع GitHub على فرع `main` أو `master`، يبدأ البناء عند push. ويمكن تشغيله يدوياً من تبويب Actions عبر workflow باسم **Build CITY LIFE 3D APK**. عند نجاحه سيظهر Artifact باسم **CITY-LIFE-3D-V3-MEGA-WORLD-APK** ويمكن تنزيل APK منه.

## ملاحظات الأداء والحدود الحالية

- كبر الخريطة يزيد عدد المجسمات وحسابات التصادم؛ الأداء الفعلي يعتمد على معالج ورسوميات الهاتف.
- الرسومات حالياً منخفضة/متوسطة التفاصيل الإجرائية، وليست نماذج سيارات أو شخصيات عالية التفاصيل. لا توجد حتى الآن خامات PBR أو ظلال ديناميكية حقيقية أو مبانٍ قابلة للدخول.
- توجد 8 فئات شكلية للمركبات مع 32 مركبة مرور نشطة، وليست 60 سيارة فريدة بنماذج مستقلة.
- الموسيقى أصلية ومولدة رقمياً داخل الكود (3 حلقات قصيرة قابلة للتكرار)، وليست ملفات أغاني مسجلة أو أغاني لفنانين.
- نظام الشرطة المتقدم، اقتصاد شراء وبيع السيارات، حفظ التقدم، العالم الداخلي للمباني والمهام القصصية الطويلة لم تكتمل بعد.
- ملف ZIP لم يُبنَ باستخدام Android NDK/Gradle داخل هذه البيئة؛ يجب تشغيل GitHub Actions للتأكد من بناء APK النهائي، ثم اختباره على هاتف فعلي.
