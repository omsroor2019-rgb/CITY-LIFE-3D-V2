# CITY LIFE 3D — NOVA BAY EDITION (V2)

نسخة جديدة من لعبة عالم مفتوح ثلاثية الأبعاد للأندرويد، مكتوبة بلغة C باستخدام raylib 5.5 وقالب raymob. العالم والرسوم تُنشأ برمجياً من مجسمات ثلاثية الأبعاد؛ لا تحتاج النسخة إلى صور أو نماذج خارجية.

## محتويات المستودع

```text
CITY-LIFE-3D/
├── .github/
│   └── workflows/
│       └── android-apk.yml
├── src/
│   └── main.c
├── .gitignore
└── README-AR.md
```

## محتوى V2

- مدينة NOVA BAY أكبر، مع شبكة شوارع من 8×8 كتل عمرانية وساحة مركزية ونافورة.
- مبانٍ متعددة الأنماط والارتفاعات، واجهات زجاجية، نوافذ، شرفات، واجهات محلات وتفاصيل أسطح.
- أشجار وأرصفة وأعمدة إنارة وعلامات طرق وممرات مشاة.
- شخصية منظور ثالث برسوم متعددة الأجزاء وتحريك بسيط للأطراف.
- ركض وقفز وركوب السيارة والخروج منها.
- سيارة قابلة للقيادة مع توجيه وتسارع وفرامل وحدود وتصادم أولي مع المباني.
- 12 سيارة مرور متحركة و22 شخصية مشاة تتحرك على مسارات المدينة.
- ثلاث مهمات توصيل (استلام ثم تسليم) ومكافآت مالية.
- عصا تحكم افتراضية وأزرار لمس: تفاعل، قفز، ركض، بنزين وفرامل.
- شاشة عنوان، إيقاف مؤقت، خريطة مصغرة، مؤشر سرعة وواجهة لعب جديدة.

## التحكم

على الهاتف: العصا اليسرى للحركة أو توجيه السيارة. زر ACTION يتغير حسب الموقف (دخول السيارة أو الخروج منها أو التفاعل مع المهمة). زر JUMP للقفز، وزرا GAS وBRAKE للقيادة، وزر SPRINT للركض. زر II يوقف اللعبة.

على الكمبيوتر للاختبار: WASD أو الأسهم للحركة والتوجيه، E للتفاعل، Space للقفز/الفرامل، Shift للبنزين، Ctrl للركض، وEsc للإيقاف.

## بناء APK عبر GitHub Actions

ملف البناء الموجود في `.github/workflows/android-apk.yml` يستخدم Android SDK وNDK وCMake ويجلب قالب `KarvinJ/raylib-mobile` تلقائياً، ثم ينسخ `src/main.c` إلى مشروع Android ويجمع Debug APK. عند نجاح البناء، يظهر Artifact باسم `CITY-LIFE-3D-V2-APK`.

## ترقية النسخة السابقة على الهاتف

هذه النسخة تستخدم اسم الحزمة نفسه `com.citylife3d.game` ورقم إصدار أعلى. إذا رفض Android تثبيتها فوق النسخة السابقة بسبب اختلاف توقيع Debug بين عمليتي بناء GitHub، احذف النسخة القديمة أولاً ثم ثبّت APK الجديد. إزالة التطبيق القديم قد تحذف بياناته المحلية.

## حدود النسخة الحالية

هذه لعبة مستقلة قابلة للعب ونموذج عالم مفتوح موسّع، وليست لعبة AAA بحجم GTA. الرسوم مبنية من مجسمات raylib الإجرائية وليست شخصيات/سيارات ممسوحة ضوئياً أو نماذج واقعية عالية التفاصيل. لا يوجد حالياً حفظ دائم للتقدم، أو صوت وموسيقى، أو نظام شرطة وقتال، أو ذكاء مرور متقدم، أو تصادم بين جميع الشخصيات والسيارات. يمكن إضافة هذه الأنظمة لاحقاً على مراحل.

## التحقق

تم التحقق من صياغة C99 باستخدام فحص نحوي محلي بواجهات raylib mock، ومن صياغة ملف YAML. هذا ليس بديلاً عن بناء NDK/Gradle؛ يجب تشغيل GitHub Actions للتأكد من التوافق النهائي مع القالب الفعلي ثم اختبار APK على هاتف حقيقي.
